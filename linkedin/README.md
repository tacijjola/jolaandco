## The simple rule (so this never feels confusing again)

- **The chat is just conversation.** It doesn't matter which chat or "project" you start in — nothing important lives *in* a chat.
- **The folder is what's permanent.** Anything you'll want later must be saved as a **file in this folder**. That's the source of truth.
- So: chat wherever is convenient → ask for the output to be **saved into this `linkedin` folder** → done. You'll always find it here, on your computer, forever.
